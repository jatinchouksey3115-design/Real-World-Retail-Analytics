# Real-world Retail Analytics Project

End-to-end retail/e-commerce analytics project aligned with the Thiranex tutorial.

## Workflow
- Load and preview transaction data
- Data understanding and preparation
- Total sales, revenue and average order value
- Unique customer analysis
- Product and category analysis
- Daily/monthly sales trends and moving average
- Customer spend segmentation
- Market basket product-pair analysis
- Business questions, insights and recommendations

## Dataset
A synthetic retail transaction dataset designed to resemble real e-commerce transactions for educational/internship use.
